Neon Pursuit — a high-speed neon police chase through Neon Bay: dodge traffic and roadblocks, drift, boost on nitro, and outrun the NPD. An open-world crime game in the spirit of GTA 6, built for make.fun's $1,666 Make GTA 6 bounty. Steal the mayor's prototype, survive the five-star dragnet, and chase the next drop.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome. Keyboard: arrows / WASD to drive, SPACE to drift, SHIFT for nitro, P to pause, M to mute. Best score is saved in your browser.
